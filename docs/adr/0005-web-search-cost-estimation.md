# Web検索コストを推定してトークンベース集計に加算する

セッションログのusageトークンには載らないコストのうち、web_searchツールの従量課金($10/1,000リクエスト)だけを対象に推定コストを算出する。web_fetchはusageのserver_tool_useに回数が乗るがAnthropicの現行料金では追加課金が無いため対象外、code_executionはusageオブジェクトに使用量自体が記録されないため対象外(コンテナ稼働時間ベースの課金で、セッションログから推定する手段が無い)。クラウドセッション(claude.ai/code、モバイルアプリ、Claude Tag)などローカルの`~/.claude/projects/`に一切ログが残らない利用も同様に対象外とする(スコープはあくまで「ログはあるが未集計」なコストであり、「ログが無い」利用の推定は別の意思決定を要するため踏み込まない)。

web_searchの単価はモデルに依存しないため、モデルごとの単価テーブル(`[models.*]`)とは別に`config.toml`の`[server_tools.web_search]`セクションで管理する。集計も既存の「使用量(Usage)」のトークン種別には混ぜず、プロジェクト・期間単位の並行したリクエスト数カウンタとして扱う。単価が未設定の場合は不明モデルと同じ考え方で「不明」として扱い、リクエスト数自体は表示するが金額には含めない。

表示は常に「既存集計(トークンのみ)」と「既存集計+Web検索推定加算後」の2系統を併記する。Web検索の有無に関わらず常に両方を出すことで、ユーザーが両者の差分を毎回確認できるようにする。
